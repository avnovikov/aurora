# Story: Plan screen redesign, with Easier and an undoable Not for me

As someone planning my mornings, I want each day on the Plan screen to read as a step on a timeline, and each exercise to offer an easier step and an undoable "Not for me", so that I can ease a day off in one tap and take back a mistaken exclusion without hunting through the Library.

## Acceptance criteria

- [ ] Days hang off a vertical rail (timeline spine). Each day has a node on the rail; today's node is filled.
- [ ] Drag handles sit at the right edge of each day; dragging still reorders days.
- [ ] Today's duration is the one accent figure on the page.
- [ ] Each exercise row shows its name and dose across the full width, so names stay on one line.
- [ ] Under each row, an action line has **Swap** and **Easier** as an equal pair (44px high) and **⋯** at the far right.
- [ ] ⋯ opens a menu with **Not for me** ("Keep this move out of all your sessions").
- [ ] Swap still toggles the swap options (`data-swap`, `aria-pressed`).
- [ ] Accessible names name the exercise and the day ("Easier: Bodyweight squat, Today"), unique per row.
- [ ] **Easier** puts the move's easier progression step into that day's slot (domain layer, `src/plan/dayEdits.ts`). The step comes from the ladder (`easierStep`), else the move's own "Easier" link that the exercise page shows, and only if the athlete can do it (gear, joints, exclusions) and it is not already in the day.
- [ ] The easier move's dose comes from the planner and library rules, exactly as when it is swapped in; nothing is copied, scaled or invented. A test proves the dose equals the rules' dose at the athlete's level.
- [ ] A move with no easier step has Easier disabled, with the reason "No easier step".
- [ ] Status after Easier reads "Easier: Hip hinge → Glute bridge" with real names.
- [ ] **Not for me** keeps today's behaviour (excludes the move, puts the best substitute in the slot) and then shows an **Undo** notice in that row.
- [ ] Undo is a real inverse in the domain layer: it removes the exclusion and restores the slot exactly as it was stored. Tested.
- [ ] Make this day, Move, Level and Add days are restyled per the mock and keep working.
- [ ] Every existing `data-*` hook keeps working; tests in `tests/plan` and `tests/ui` pass.
- [ ] Colours only through role variables; works in all six palettes; 4px grid; 44px targets; British English.

## Out of scope

- Doodles in exercise rows (the mock shows them; the app's rows open a description instead, and doodles are not to be touched).
- Changes to how the planner doses or progresses moves.
- The Library's own restore flow.
