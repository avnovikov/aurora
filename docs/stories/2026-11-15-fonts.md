# Story: bundled IBM Plex fonts

As a person training in the morning with Aurora on my Android phone,
I want the app to show IBM Plex Sans for text and IBM Plex Sans Condensed for headings and big numbers,
so that it looks the way the design says, even offline in the APK, instead of falling back to Roboto.

## Acceptance criteria

- [ ] `@fontsource/ibm-plex-sans` and `@fontsource/ibm-plex-sans-condensed` (v5, OFL) are dependencies.
- [ ] `src/main.ts` imports only the latin subset of the weights in use: sans 400/500/600/700, condensed 500/600/700.
- [ ] `src/style.css` `:root` defines `--font-body: "IBM Plex Sans", Roboto, sans-serif;` and
      `--font-display: "IBM Plex Sans Condensed", "Roboto Condensed", sans-serif;`.
- [ ] `:root` uses `var(--font-body)`; every former "Arial Narrow" / "Helvetica Condensed" / Impact stack uses `var(--font-display)`.
- [ ] No network font loading (no Google Fonts); `npm run build` emits the woff2 files with relative/bundled URLs that work in Capacitor.
- [ ] A vitest checks the variables, the absence of the old stacks, and the fontsource imports in `main.ts`.
- [ ] In the browser, `document.fonts.check('16px "IBM Plex Sans"')` and the condensed check are true; Today and Settings checked in rassvet and ushas.

## Out of scope

- Any other restyling (sizes, layouts, spacing): the screen stories handle that.
- Doodle SVG text.

## Files touched

- `package.json`, `package-lock.json`
- `src/main.ts`
- `src/style.css` (`:root` font variables and the four display-font stacks only)
- `tests/brand/fonts.test.ts`
- `docs/stories/2026-11-15-fonts.md`
