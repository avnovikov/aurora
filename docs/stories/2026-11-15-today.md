# Story: Today screen redesign

As someone training first thing in the morning, phone in one hand,
I want the Today screen to show what I am doing at the top and put the check-in and Start within thumb reach,
so that I can read the plan, answer two questions and start without stretching or scrolling.

Design source: `.desk/out/20261115-2140-today-screen-redesign/final-plex.html` (signed off).

## Acceptance criteria

- [ ] Reading area at the top: "Aurora · Rassvet" eyebrow, the "Today" title, then "Next up" (or "Today instead") with the duration ("≈ 32 min") on the same row.
- [ ] The session name is big, in the display font, in the foreground colour (not accent).
- [ ] The goal line ("Toward Pistol squat") sits under the name, then the warm-up line (`data-warmup-preview`), then the core and deload notes when they apply.
- [ ] A surface panel below holds the check-in: sleep as three equal buttons in a row, pain as a 3-column grid of toggles, Start full width, hints under it.
- [ ] Start is the only accent element on the screen. It stays disabled until sleep is picked and is linked to its hint with `aria-describedby`; the link is dropped when the hint goes.
- [ ] Pressed sleep and pain buttons use the foreground (border, inset ring, tint), not the accent, and keep the check mark / filled box, so selection is not colour-only.
- [ ] Below the panel: Coming up, then the "Train something else today" disclosure (top and bottom rule, chevron), then the tab bar.
- [ ] All labels, numbers and data-* hooks stay (`data-checkin`, `data-start`, `data-start-hint`, `data-sleep-value`, `data-joint`, `data-forecast`, `data-override*`, `data-deload-note`, `data-warmup-preview`); the Start flow (readiness → planSession) is unchanged.
- [ ] Colours only through the role variables; works in all six palettes. 4px grid, 44px minimum touch targets.
- [ ] New styles live in `src/styles/today.css`, imported from `src/ui/todayHome.ts`; the old Today-only rules in `src/style.css` are removed.

## Out of scope

- The tab bar (shared shell) and the palette mock control from the mock.
- Font files and the `--font-*` variables (fonts story).
- Any change to the planner, doses or check-in logic.
