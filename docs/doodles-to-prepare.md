# Doodles to prepare

Moves the planner can put in a session that have no doodle yet: 59 of the 113 moves it plans. Every warm-up and cool-down station (43) already has one.

How the list was made: every seed day run three times in a row (so the variety rule rotates moves in), every added area and skill day at every plan level, and every joint care day (general and each joint), each with three gear sets: bar and bodyweight; plus a band; and all gear.

\*Times planned is how often the move came up across those runs. It is a rough guide to how often someone will see the move, not a count from real sessions.

To add one, write a spec in `src/doodles/specs.ts` with the exercise id as its `id`, then run `npm run doodles`. That renders `public/doodles/doodle-<slug>.svg` and maps it to the move.
